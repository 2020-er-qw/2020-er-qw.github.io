整件事的起点不是代码，是一句话。我对 AI 说："想想基于全网的数据，看看玩家最喜欢什么类型的游戏，形态就走最快上线和变现的纯 H5 模式。"

一天之后，一款能玩的游戏出现在我手机上；一周之内，它出现在 TapTap 的商店页里，带图标、带宣传视频、带广告位。这篇文章把这个流程一步步拆开——每个环节我做了什么、AI 做了什么、在哪里踩了坑。看完你会发现，这件事最难的部分不是写代码。

## 第一步：一句话，先让 AI 摸清市场

我不是先想"做什么游戏"，而是让 AI 先拿数据说话。这是它给我的调研结论：

![WorkBuddy 一句话启动：市场调研结果](/images/taptap-story/wb-research.jpg)

几个关键数字，直接决定了后面的方向：

- **市场规模**：小游戏约 700 亿/年，增速是大盘的 3 倍，微信小游戏月活 6.5 亿；TapTap 走的是另一条路——玩家更年轻、社区氛围重、评分决定曝光
- **赛道**：益智类份额从 40% 涨到 60%，是第一大赛道；模拟经营增速超 200%，合成消除 70%+
- **爆款三规律**：零门槛 + 高难度落差（第一关幼儿园水平，后面突然变难）、一局 30 秒~3 分钟、社交货币（排行榜、好友 PK）
- **变现数据**：激励视频是印钞机——玩家看广告换"复活/双倍奖励"的主动观看率高达 50-65%，广告位放在"失败瞬间"和"卡关时刻"转化最高

基于"TapTap + 纯 H5 + 最快上线变现"这三个约束，我选了**排序消除类**：规则三秒讲完，难度上限极高，而且玩法逻辑清晰，适合 AI 一次成型。

形态决策比选玩法更重要：**单个自包含 HTML 文件**。不用构建工具、不用引擎、零依赖，双击就玩。理由很冷——H5 是从代码到 TapTap 商店页最快的路，我跳过的每一层工具链，都是上架当天少一个会炸的地方。

## 第二步：AI 写游戏，我负责挑毛病

可玩的 v0.1 几个小时就出来了：彩球排序、整管自动消除、撤销、程序化音效、触屏适配。这是全程最容易的部分。真正的迭代发生在"我拿手机玩"之后——前前后后改了八个版本，每一版都源自实际玩出来的问题：

![第 5 关进行中](/images/taptap-story/game-level5.jpg)

- **球的形状不对**：早期版本彩球会拉伸撑满整根试管——物理上不该这样。修完之后我把这段 CSS 锁死并注释"不许动"，防止以后的版本手滑改回去。
- **没有新手引导**：第一版直接把玩家扔进游戏。加了三步引导关：点管取球 → 点空管放入 → 凑满同色消除，第一关手工布局保证任何人都能赢。
- **一次只能倒一个球**：隐藏 bug，顶部连续同色的球应该一起倒过去，修完手感立刻顺了。
- **"太简单了，一口气玩到 18 关"**——这句抱怨变成整个项目最有价值的一次排障。我本来以为是难度参数没调够，实测后发现真相更糟：把打散参数从 6 调到 30，生成的棋盘逐字节一模一样。打散算法在数学上就是坏的，调参救不了。
- **修法成了核心技术**：放弃盲生关卡，写一个 IDDFS 求解器，随机生成候选棋盘，只保留"最优解落在目标难度区间"的。30 个主线关卡 + 64 层无尽模式棋盘，批量算了 36 分钟，以静态数据烤进游戏。所有玩家在同一关拿到同一张棋盘，成绩可比，速通才有意义。

后来又补了主线 30 关 + 无尽挑战的双模式结构（步数预算制，每层限步）、断线续玩存档（每步落子写盘，重开页面接着玩）。这一路我反复学到同一件事：**AI 写代码很快，但它感受不到难度、公平和好玩。验证必须作为独立工程来做**——到最后我有一整套 Playwright 脚本实机通玩全流程、BFS 求解器算最优路线、每次存档改动都有回归检查。

## 第三步：注册 TapTap 开发者，打包上传

游戏有了，接下来是上货架。TapTap 开发者注册免费，个人就能申请。我在后台建了厂商「摸鱼游戏社」，然后创建游戏、补全资料。下面这个界面就是你提交后的全部家当：

![TapTap 开发者后台：厂商下的两款游戏](/images/taptap-story/taptap-console.png)

有几个坑要提前知道：

**坑一：你看到的入口可能不是你要的。** 后台"版本发布"页默认露出的是 Android/iOS 安卓包路线，纯 H5 的 zip 包看起来"没地方传"。实际上同一个页面支持 H5 包体（宣传图 1920×1080 + zip 包体两个输入框），H5 走小游戏体系。

**坑二：zip 结构有硬性要求。** 我第一次上传直接报"压缩包解析失败"。试出来的规则：解压后根目录**必须只有一个文件夹**，且该文件夹里有 `index.html`。不是文件散在根目录——必须套一层：

```
彩球大排序_v1.0.0.zip
└── game/
    └── index.html
```

文件夹名用纯英文（我用 `game`），躲开中文编码的坑。五行 Python 脚本搞定打包，之后所有游戏复用。

**坑三：表单逐项填，别低估工作量。** 游戏名称、类型、简介、首页推荐语、开发者信息……其中"首页推荐语"限 25 字，比想象中难写——它是商店页第一眼那句话。填完右侧有手机实时预览，确认商店页长什么样再提审：

![版本发布页：逐项填写 + 手机预览](/images/taptap-story/taptap-publish.png)

提审后审核 turnaround 大概一两天。这里插一个诚实的教训：我首版是以"测试版"状态上线的，白白浪费了首发曝光窗口——新游戏上线当天平台会推一波流量，这个机会只有一次，务必以正式版身份提审。

## 第四步：AI 生成全套上架素材

TapTap 要求：图标、三种比例的宣传图、六张实机截图、一段真实试玩视频。请设计师？不存在的。这一整套我全靠 AI 加脚本生成：

![WorkBuddy 生成全套上架素材的交付清单](/images/taptap-story/wb-assets.png)

对应到《侯府丫鬟·浮沉录》（我做的第二款）这次交付清单：512×512 游戏图标、竖版封面 1200×1800（2:3 必填位）、横版宣传图 1920×1080、六张 1080×1920 实机截图、21 秒宣传视频。每一样怎么来的：

- **图标和宣传图**：参数化 SVG + 无头浏览器截图渲染。渐变、光晕、配色全部写成可调参数，改四个常量，所有要求的尺寸一次重出。第二款游戏换个主题色和字体，一小时出全套。
- **实机截图**：Playwright 加载真游戏，注入一个中期游戏状态（分数、步数、结算面板），按 360×640 逻辑尺寸、3 倍缩放截屏——出来就是原生 1080×1920，UI 元素大小和真机完全一致。不是 P 图，是从真实产品里截出来的真画面。
- **宣传视频**：BFS 求解器逐步操作真游戏，Playwright 同步录屏。21 秒、1080p、H.264。内容是真实的点击流程：选身世 → 当差 → 学艺 → 触发事件做选择，抽帧确认没有黑屏。

**审核驳回的教训必须单拎出来讲**：我的第一版宣传图上写了"30 关闯关 + 无尽挑战"，封面写了"轻松上手"——全被驳回。TapTap 的规则是：**商店图上只允许出现游戏名称，所有卖点一律写进简介文字**。我把两张图重做成只剩标题+主体画面才过审。当时觉得反直觉，封面图存在的意义不就是钩子吗？但规则就是规则，现在它焊死在我的上架清单里。

另一个小坑：AI 生成的图和视频自带水印（图片在右下角，视频会在左上+右下两处）。统一用裁切的方式去干净，再压成目标格式。

## 第五步：上线之后，广告藏在一个开关后面

首版上架我刻意**全关广告**：`AD_ENABLED = false`，入口隐藏，代码完好。理由是先保审核和评分，等有了玩家再统一开。所有广告代码原封不动留在代码里，藏在总开关后面——包括三个激励视频位（撤销用尽 +3 次、加一根空管、过关双倍奖励，全部绑在玩家主动点击上）和一个插屏（每 3 关一次、冷却 3 分钟）。

开放广告那天，实际操作比想象简单：用 TapTap 官方的 MCP 工具扫码授权，广告位 ID 自动查回来（不用去后台翻页面），填进配置，重新打包提审。SDK 没就绪时所有广告调用静默失败——最坏情况是玩家没拿到奖励，游戏永远不会被卡住。

再往后就是真实的数据课：上线九天，商店页浏览 21 次，下载 0 次，点击率 0.3%（健康值 3-10%）。复盘下来：首发窗口浪费了、商店素材守规矩守到没有钩子、休闲益智是分发效率 0.44x 的红海。这些都不是流水线的失败——素材工具、验证脚本、打包脚本、提审清单全部可以原样复用到第二款，换更好的赛道数据和一张既守规则又能让人停下滑动的封面。

## 这套流程的复用清单

如果你也想走一遍，最小可行版本是这六步：

1. **一句话调研**：让 AI 拿数据选赛道，锁定"零门槛 + 高难度 + 30 秒一局"的品类
2. **单文件 H5**：不引入任何构建工具，游戏就是一个 HTML
3. **实机验证**：每版改动用无头浏览器自动化跑全流程，别靠感觉
4. **打包**：zip 根目录一个英文文件夹 + index.html，脚本固化
5. **素材**：图标/宣传图参数化生成，截图和视频从真游戏里截录，图上只放游戏名
6. **提审**：正式版身份上线，别浪费首发窗口；广告代码先留好，开关后置

AI 把"做出一款游戏"从几个月压缩到几天，把"做对它"从碰运气压缩成工程。它一点都没有压缩的，是"让有人在乎"——这一段还是我自己要解的题。第二款游戏怎么攻这一点，到时候再写给你。
